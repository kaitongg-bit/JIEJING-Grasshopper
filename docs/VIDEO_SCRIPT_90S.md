# 90-second demonstration video

## Recording format

- 1920 × 1080, 30 fps
- Record Rhino and Grasshopper side by side
- Use the same `cat3-input.png` shown in the README
- Keep the mouse movement slow and crop out unrelated desktop windows
- Add short on-screen labels; narration can be recorded afterward

## Shot list and English narration

### 0:00–0:08 — Problem and concept

**Visual:** Title card, cat input, and finished black-and-white preview.

**Voice-over:**

> JIEJING is a beginner-friendly Grasshopper toolkit that turns a window boundary,
> traditional lattice logic, and an optional personal image into fabrication-ready
> Chinese window patterns.

### 0:08–0:20 — Open the Baby Starter

**Visual:** Open `JIEJING_Baby_Starter.gh`; briefly point to the four numbered areas.

**Voice-over:**

> The Baby Starter is already connected. A user only needs to set the window size,
> choose a pattern, optionally define a borrowed view, and preview the result.

### 0:20–0:35 — Traditional parametric controls

**Visual:** Change width, height, recipe, density, and line weight. Show live Rhino update.

**Voice-over:**

> Fourteen built-in recipes provide different geometric families. Density and member
> width remain parametric, so the same rule can adapt to different windows and fabrication
> constraints.

### 0:35–0:50 — Borrowed view

**Visual:** Turn Borrowed View on, select Begonia or Ellipse, adjust amount.

**Voice-over:**

> Borrowed View introduces intentional openness instead of filling the entire panel.
> Its profile and scale can frame a landscape, an object, or a focal area.

### 0:50–1:08 — Cat image field

**Visual:** Right-click IMAGE FILE → Select one existing file → choose `cat3-input.png`.
Switch between Silhouette, Portrait Detail, and Hybrid; adjust strength once.

**Voice-over:**

> A personal photograph can also control the lattice. This is not generative AI. The
> plugin extracts contrast and edge information, then maps it to the size and openness
> of repeated cells, keeping the result editable and reproducible.

### 1:08–1:22 — Material preview and export

**Visual:** Show black material preview, then toggle Export to True and reveal the output
folder containing DXF, SVG, PDF, and PNG.

**Voice-over:**

> The material preview distinguishes what remains from what is cut. One switch exports
> one-to-one DXF, SVG, and PDF files for CAD and laser-cutting workflows.

### 1:22–1:30 — Closing

**Visual:** Cat input and final circular preview side by side; end on the JIEJING logo/tab.

**Voice-over:**

> JIEJING connects traditional spatial ideas with accessible parametric customization—
> from a personal image to a manufacturable window screen.
