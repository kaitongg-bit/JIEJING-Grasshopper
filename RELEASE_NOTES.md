# JIEJING 0.2.4

Initial academic release candidate for Rhino 8 and Grasshopper.

## Included

- Eight JIEJING components and four toolbar selectors
- Fourteen curated parametric lattice recipes
- Ten borrowed-view profiles
- Non-AI image field with silhouette, portrait-detail, and hybrid modes
- Black-and-white material preview
- DXF, SVG, PDF, PNG, and JSON export workflow
- Prewired Baby Starter and reusable Modular Starter
- Cat input and material-preview documentation example

## Verification

- Baby Starter: zero errors and zero warnings with optional image unset
- Installed toolbar icons and selectors verified in Rhino 8 for Mac
- Image file input uses Grasshopper's native File Path component
